# Разминка

Десять ежедневных головоломок на русском: слова, числа, география. Статический сайт, никакой сборки. Живёт на GitHub Pages: https://ykyki4.github.io/razminka/

## Запуск и выкладка
- **Локально:** `Запустить.bat` (или `python tools/serve.py`) → http://localhost:8765/. Открывать `index.html` прямо с диска не стоит: Firefox даёт каждому файлу своё хранилище, и главная не видит прогресс игр.
- **SEO и превью ссылок:** тексты — в `tools/seo.json`; `python tools/build_seo.py` вписывает мета-теги в страницы и пересобирает `sitemap.xml`, картинки `assets/og/*.png` рисует `cd tools && node build_og.js` (при запущенном `serve.py`).
- **Выкладка:** `python tools/version.py` (метки `?v=` против старого кэша у игроков), затем `git commit` и `git push` — GitHub Pages обновится сам за минуту-две.

## Как устроено
- `assets/core.js` — общее (там же список игр `GAMES` для главной и шапок): номер дня (по Москве, №1 = 17.10.2026), сохранения и статистика в localStorage, клавиатура (понимает и английскую раскладку), окна, шеринг.
- `?practice=<что угодно>` — тренировка со случайным заданием (кнопка ∞), на статистику не влияет.
- `?d=N` — открыть задание дня N (для проверки).
- Ответ дня берётся по индексу из заранее перемешанного списка `a5` / `a4`, у каждой игры свой сдвиг, поэтому в один день слова разные.

- `assets/geo-core.js` — общее для географии: поиск страны по названию и синонимам, расстояния, стрелки, поле ввода.

## Данные по странам
`data/geo.js`, `assets/flags/` и `assets/vendor/` собираются так:

```
cd tools && npm install && node build_geo.js
```

Источники в `tools/raw/`: mledoze/countries (названия, координаты, площадь), население World Bank, границы Natural Earth 1:50m (пакет world-atlas), флаги flag-icons. Синонимы названий («США», «Англия»…) — в `NAMES` внутри `build_geo.js`.

## Словарь
`data/words.js` и `data/soty.js` генерируются скриптом:

```
python tools/build_dict.py
```

Нужен `pip install pymorphy3 pymorphy3-dicts-ru` и исходники в `tools/raw/` (существительные Harrix/Russian-Nouns и частотный список hermitdave/FrequencyWords).
- Допустимые слова — все существительные в начальной форме нужной длины.
- Ответы — частотные существительные, ед. ч., им. п., без имён, географии, мата и жаргона.
- Неудачные ответы дописывай в `tools/blacklist.txt` и пересобирай.

Пересборка не трогает ответы уже идущих дней: порядок берётся из текущего `data/words.js`, новые слова дописываются в конец, а слово, попавшее в чёрный список, заменяется на месте. Задания «Сот» (`SOTY_PUZZLES` в `data/soty.js`) так же только дописываются.
